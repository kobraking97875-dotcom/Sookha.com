# ShareNest — login-first single-file build

Open `index.html`. This version has CSS and JavaScript embedded in the HTML so it renders correctly even when opened directly from a phone/file manager.

First screen is Login / Create account. After successful login, the website opens.

Includes the requested 1–5 photo upload, automatic 6206085383 watermark, profiles, posts, dashboard, analytics, membership plans and Razorpay test checkout.

For production permanent accounts, storage, Google OAuth, payment verification and AutoPay, connect Supabase and Razorpay Live on a backend. Never place secret keys in the HTML.
